# 設計目標

## 唯一產品目標

桌面版可遊玩的可愛城市，接近使用者提供的參考圖：
[目標圖](../references/target-town.png)。

粉彩天空、圓潤建築、柔和陰影、清楚道路與店名、可辨識的主角、奶油白及粉紅 UI。
參考圖是視覺方向，不能當成一張全螢幕背景覆蓋互動元件。既有玩法必須仍可操作。

驗收尺寸：1280×720、1536×990、1920×1080，100% browser zoom。
主要美術方向：柔和繪本 chibi；同一場景的角色、道具、建築在描邊、透視和陰影上協調。

## 角色

參考圖的棕髮、雙馬尾、藍裙主角作為品牌方向。玩家已保存的髮型、髮色、膚色、眼色與衣服選擇必須保留並且看得見。
不能把紫髮玩家強制顯示成棕髮角色來達成「一致」；品牌肖像和玩家肖像必須明確區分，或直接從玩家渲染器產生肖像。
站立、坐下、睡眠和反應姿勢要符合動作，不能把單一慶祝姿勢用於所有狀態。
材質透明檢查要包括完整背景和角色內部，不只檢查四個角落。禁止棋盤底、光暈、破洞及鋸齒污染。

## 場景與介面

城鎮全部九個地點可見：Home、Pet Shop、School、Park、Café、Boutique、Market、Toy Shop、Salon。
店名不可被其他建築或固定 UI 遮住。主角在中央道路清楚可辨，不壓住必需操作區。
室內物件落地、有合理比例，不將完整外觀建築當室內家具。角色不穿過櫃台或被面板完全蓋住。
商品完整顯示名稱、圖像、價格、擁有／預覽／購買狀態；滾動後最後一項及操作按鈕可到達。
角色編輯必須看到即時結果。所有入口、提示和按鈕狀態應可辨識。

## 範圍

本輪處理桌面美術和相關呈現回歸。新增地點、經濟重設、存檔格式變更、移動端重設和新玩法不在本輪。
